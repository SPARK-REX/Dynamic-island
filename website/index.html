Capabilities

Built with Windows Native Engineering

No Electron bloat. No 500MB web wrappers. Built with .NET 10, C# 13, and hardware-accelerated Windows Composition APIs.

Fluid Mouse-Wheel Navigation

Cycle between views with zero clicks. Simply scroll your mouse wheel over the island to fluidly glide between Clock, Media Controls, Focus Timer, and Clipboard History with hardware-accelerated spring animations.

Zero-Click Multi-View

Featherweight Efficiency

Zero Electron overhead. Built with non-server GC and memory conservation flags, idling under 18MB RAM with 0% CPU consumption. Unobtrusive, battery-friendly, and gamer-ready.

< 18MB RAM • 0% CPU

WASAPI Audio Loopback

Zero-latency audio capture using Windows Audio Session API (NAudio.Wasapi). Live FFT frequency analysis brings true dynamic waveforms to your desktop.

Sub-5ms Latency

Always-on-Top Floating Notch

Pins smoothly to the top bezel of your monitor with smart multi-display DPI awareness and pass-through input options when not in focus.

Multi-Monitor Ready

Aggressive GC Memory Conservation

Configured with System.GC.ConserveMemory=5 and non-server GC. Idles at under 18 megabytes of RAM without starving your GPU or background games.

< 18 MB RAM

Zero Spyware & Zero Telemetry

100% verified private. No tracking beacons, no analytics servers, and no background network calls. All logic runs strictly locally on your machine.

Fully Offline
